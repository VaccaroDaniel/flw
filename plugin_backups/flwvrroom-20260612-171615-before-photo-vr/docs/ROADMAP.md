# FLW VR Room Roadmap

## Phase 1: MVP activity

- Scenario presets for cafe, classroom, hotel, airport, and supermarket.
- CEFR and knowledge point fields.
- Hotspot scoring.
- Mission quiz.
- Attempt saving.
- Gradebook and completion support.

## Phase 2: Teacher-editable rooms

- Upload background room image.
- Add, move, and label hotspots.
- Add text, audio, and image prompts.
- Configure object scores.
- Create reusable room presets: cafe, classroom, hotel, airport, supermarket.

## Phase 3: FLW learning analytics

- Attempt history report.
- Per-knowledge-point performance.
- Class completion dashboard.
- Export CSV for teachers.

## Phase 4: AI speaking practice

- Record learner speech.
- Connect to local or cloud STT.
- Score pronunciation, vocabulary, grammar, and task completion.
- Save AI feedback with the attempt.

## Phase 5: WebXR / AR support

- 360-degree scene mode.
- WebXR headset mode.
- AR object label mode.
- Local HTTPS support for offline/LAN headset testing.
