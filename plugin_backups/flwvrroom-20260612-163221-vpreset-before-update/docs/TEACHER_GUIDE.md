# Teacher Guide

## Purpose

FLW VR Room gives learners a simple situation practice room. The MVP focuses on a cafe scene for A1 speaking/listening readiness.

## Learner task

The learner should:

1. Click the five cafe objects: waiter, menu, cup, table, cashier.
2. Read the waiter prompt.
3. Choose the reply: "I would like a coffee, please."
4. Save the attempt.

## Score

The MVP score is:

- Waiter: 20
- Menu: 15
- Cup: 15
- Table: 15
- Cashier: 15
- Correct mission answer: 20

Total: 100

The default passing grade is 70.

## FLW mapping

Recommended A1 knowledge points:

```text
A1-VOC-FOOD-001
A1-FUNC-ORDER-001
A1-LIS-QUESTION-001
A1-SPK-REPLY-001
```

## Classroom use

Use this as a five-minute practice activity after teaching cafe vocabulary and the function "I would like...".

For offline or LAN classrooms, keep all media local and test with the same browser students will use.
