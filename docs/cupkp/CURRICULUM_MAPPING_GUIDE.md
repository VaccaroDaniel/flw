# Curriculum Mapping Guide

Map from broad to fine-grained evidence:

- Competency: integrated can-do outcome with direct performance evidence.
- Use Point: assessable communicative action.
- Knowledge Point: language resource, processing skill, strategy, or form-meaning relationship.
- Learning object: lesson, activity, quiz item, speaking task, writing task, project, SCORM/H5P item, or resource.

Vocabulary, grammar, pronunciation, listening, reading, and controlled practice primarily generate KP evidence. Speaking, writing, projects, and portfolio tasks can generate UP or competency evidence when the task requires integrated performance.
