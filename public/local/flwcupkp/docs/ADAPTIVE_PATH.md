# Adaptive Path

Recommendation priority:

1. unresolved mandatory prerequisite KPs;
2. review-due KPs;
3. low-confidence required KPs;
4. weak UP performance;
5. upcoming competency requirements;
6. extension or transfer activities.

Each stored recommendation includes target type, target ID, activity/object ID, reason, mastery gap, expected benefit, status, and timestamp.

The default spiral ratio is configurable and starts at 70 percent current/new target, 20 percent recent review, and 10 percent long-term review.
