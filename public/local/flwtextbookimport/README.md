# local_flwtextbookimport - FLW Textbook Importer

`local_flwtextbookimport` imports reviewed textbook/package plans into Moodle course shells. It is designed for FLW content pilots where a dry-run JSON package has already been produced outside Moodle and Moodle needs to create the course, sections, review rows, and optional learner-ready Page/Assignment activities.

Component: `local_flwtextbookimport`

Release: `0.5.0-alpha`

Requires: Moodle 4.1 or later

Status: alpha/pilot importer. Use in staging or controlled authoring courses before publishing to learners.

## What This Plugin Does

- Reads a generated dry-run JSON package.
- Creates or reuses a Moodle course shell.
- Creates section summaries from package structure.
- Stores teacher/activity review metadata.
- Creates hidden Page and Assignment activities from approved rows.
- Composes learner-ready lesson content for supported pilot lessons.
- Publishes or unpublishes one composed lesson section at a time.
- Adds a course navigation link to the review dashboard.

The importer is intentionally review-first. It does not publish all generated content automatically.

| Setting | Meaning |
| --- | --- |

Use an absolute server path for the package file.

## Input Package

The CLI expects a JSON package generated by the FLW textbook/import planning pipeline. The package should include enough information to create:

- Course short name/full name.
- Section/unit/lesson structure.
- Planned activities.
- Moodle module type.
- Source component and source PDF/page range.
- CEFR/skill/KP metadata.
- Review status.
- Teacher notes or review guidance.

The importer should receive reviewed package files, not raw OCR or unreviewed textbook output.

## CLI Tool

Run from the Moodle root.

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json
```

By default the command previews the import and does not write to Moodle.

### Write Modes

Use only one write mode at a time.

| Mode | Purpose |
| --- | --- |
| `--execute` | Create the course shell and section summaries. |
| `--create-activities` | Create hidden Page/Assignment modules from approved plan rows. |
| `--compose-lesson` | Update supported lesson placeholders with learner-ready content. |
| `--publish-lesson` | Publish only the selected composed lesson section. |
| `--unpublish-lesson` | Hide the selected lesson section again for review. |

### Common Options

| Option | Meaning |
| --- | --- |
| `--input=PATH` | Required package path. |
| `--section=N` | Target section for activity creation, composing, publishing, or unpublishing. |
| `--types=LIST` | Moodle module types to create. Default: `page,assign`. |
| `--review-statuses=LIST` | Review statuses allowed for activity creation. Default: `needs_teacher_review,needs_activity_review`. |
| `--limit=N` | Limit number of activities created. |
| `--reuse-course` | Reuse an existing matching course. |
| `--reuse-modules` | Reuse existing matching modules. |
| `--visible` | Make created/composed modules visible. Default is hidden. |
| `--json` | Print machine-readable JSON output. |
| `--help` | Show CLI help. |

### Example Flow

Preview:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json
```

Create or update course shell:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json --execute --reuse-course
```

Create activities for Lesson 1:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json --create-activities --section=1 --types=page,assign --reuse-modules
```

Compose learner-ready Lesson 1 content:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json --compose-lesson --section=1
```

Publish only Lesson 1:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json --publish-lesson --section=1
```

Return Lesson 1 to review:

```bash
php local/flwtextbookimport/cli/import_course.php --input=/path/to/dry_run.json --unpublish-lesson --section=1
```

## Current Pilot Composer

The learner-ready composer is intentionally narrow while the pilot template is validated. Current behavior:

- Supports the current Lesson 1 composer path.
- Updates matching hidden Page/Assignment placeholders.
- Keeps modules hidden unless `--visible` or publish mode is used.
- Publishes only activities considered safe by the pilot publish switch.
- Returns the course to hidden when unpublishing if no visible modules remain.

If you try to compose an unsupported section, the plugin raises a Moodle exception instead of guessing.

## Review Dashboard Workflow

1. Configure `defaultpackagepath`.
2. Run the CLI preview.
3. Run `--execute` to create/reuse the course shell.
4. Open `/local/flwtextbookimport/index.php`.
5. Review package rows, statuses, source references, CEFR, skill, and KP tags.
6. Create hidden activities.
7. Compose the lesson.
8. Visually inspect the course as teacher.
9. Publish only the reviewed lesson section.
10. Log in as learner and confirm only intended modules are visible.

## Handoff To C-UP-KP

Imported course content becomes operational learning material only after it is connected to C-UP-KP:

- Use stable unit and lesson codes in the package.
- Preserve KP tags on generated activities.
- Link created Moodle activities/questions to C-UP-KP evidence mappings.
- Keep review status visible until a teacher confirms the imported activity is instructionally safe.
- Activate the unit only after package import, link status, and teacher review pass.

## Testing Checklist

1. Run CLI preview and inspect warnings.
2. Run `--execute --reuse-course`.
3. Confirm the course exists and remains hidden unless intentionally visible.
4. Confirm section summaries match the package.
5. Confirm rows exist in `flwtbi_review`.
6. Run `--create-activities --section=1 --reuse-modules`.
7. Confirm activities are hidden by default.
8. Run `--compose-lesson --section=1`.
9. Open the course as teacher and inspect learner-ready content.
10. Publish the lesson and verify learner visibility.
11. Unpublish the lesson and verify learner visibility is removed.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| Dashboard cannot load package | `defaultpackagepath`, file permissions, and valid JSON. |
| CLI creates duplicate courses | Use `--reuse-course` and confirm package course identifiers. |
| CLI creates duplicate modules | Use `--reuse-modules` and stable activity ID numbers. |
| No activities created | Review status filters, module type filter, section number, and approved rows. |
| Composer fails | Section support and placeholder module type compatibility. |
| Learners see unfinished content | Course/module visibility and publish/unpublish state. |

## Production Notes

Do not run broad imports directly into live learner courses without staging review. Keep package files versioned, record the source textbook/PDF range for each activity, and make lesson publishing a teacher/admin decision.
