# Teacher Guide Draft — Adventure English World V2 Unit 9 Snack Time

This is a pre-HTML teacher guide draft for content/practice review. It is not the final teacher_guide.html.

## Unit Overview

- Level: Pre-A1.2
- Can-do: I can name simple foods and ask politely.
- KP: snack/drink words; I want ..., please.; a/an noticing as fixed chunks only
- Final project: My Snack Order Role-play
- Portfolio evidence: photo of snack order card + short speaking recording of the role-play

## Blocked Language Reminder

Avoid restaurant/café menu language, prices/money, would like, Can I have ..., some/any, health advice, allergies, cooking, and paragraph writing.

## Lesson Notes

### Lesson 1: Snack Words
- Use images: AEW2_U009_IMG03, AEW2_U009_IMG04
- Main support: VOC: snack words; LST: listen and point; SP: repeat single words
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: If you are not sure, look at the tray again and say one word only.

### Lesson 2: I Want...
- Use images: AEW2_U009_IMG05, AEW2_U009_IMG06
- Main support: CHK: I want ...; VOC: snack choice; SI: answer a simple choice question
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: Start with the chunk I want. Then add one snack word.

### Lesson 3: Please
- Use images: AEW2_U009_IMG07, AEW2_U009_IMG08
- Main support: CHK: I want ..., please.; REG: friendly polite asking; SI: helper/learner exchange
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: If please is missing, say the whole line again with please at the end.

### Lesson 4: A / An Snack Chunks
- Use images: AEW2_U009_IMG09, AEW2_U009_IMG10, AEW2_U009_IMG18
- Main support: GRM: a/an noticing as fixed chunks only; VOC: snack chunks; STR: repair by model copying
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: Use the repair picture. Copy the full chunk, not only the food word.

### Lesson 5: Drinks
- Use images: AEW2_U009_IMG11, AEW2_U009_IMG12
- Main support: VOC: drink words; CHK: I want water/milk/juice, please.; SI: simple choice
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: For drinks, use the drink word after I want: I want juice, please.

### Lesson 6: Snack Order Role-play
- Use images: AEW2_U009_IMG13, AEW2_U009_IMG14, AEW2_U009_IMG15, AEW2_U009_IMG19
- Main support: SI: snack order role-play; CHK: I want ..., please.; VOC: snack + drink; REG: thank you
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: If the line is too long, say it in two parts: I want a sandwich. I want juice, please.

### Lesson 7: Project Rehearsal
- Use images: AEW2_U009_IMG16, AEW2_U009_IMG17
- Main support: PRJ: project rehearsal; SP: short snack order; WRT: copy one snack word and one drink word; STR: self-check
- Teacher move: model, gesture, point, then choral repeat.
- Repair focus: Check three parts: snack word, drink word, please.
