Teaching Notes

  • Keep language as memorized chunks. Do not add new grammar explanations.
  • Use the images for pointing, matching, and short oral repetition.
  • Use one block-level audio placeholder for each model block when audio is added later.
  • For weak learners, run the repair path before the project.

Watch Script

Hello! It is Mini Quest Review.
Leo, Mia, Emma, and Toto see five badges.
Badge one: Hello. I’m Leo.
Badge two: It’s blue.
Badge three: How many? Five.
Badge four: Point. Draw. Open.
Badge five: It’s a dog. It’s a cat.
Mia says: I like cats.
Emma says: I like birds.
The team makes a mini picture mission card. Goodbye!
