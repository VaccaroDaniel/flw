Teacher Guide

Adventure English World V2 — Unit 2: Color Quest

Level: Pre-A1.1108 Practice items20 image assets

Unit Goals

Learners recognize 10 basic colors and say short chunks such as It’s red. The final output is a Color Mini-Poster and a short audio greeting.

Allowed KP

red, blue, yellow, green, orange, purple, pink, black, white, brown; It’s + color; What color?; hello / goodbye / I’m + name review.

Blocked KP

No numbers, ages, family, geography, likes/dislikes, full grammar tables, or long self-introductions.

Teaching Path

  1. Open each folding lesson and use the image as the anchor.
  2. Use sound buttons for choral repetition.
  3. Let learners complete Practice in 3-item pages.
  4. When wrong, have learners use Try again before checking Correct Answer.
  5. Finish with the mini-poster and short voice recording.
