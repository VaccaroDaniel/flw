Adventure English World V2 — Unit 3: Number Trail

Package contents:
- index.html: student Moodle HTML page
- teacher_guide.html: separate teacher guide
- assets/images/: 20 image assets
- assets/audio/: Edge TTS child-voice audio files for sound icons
- assets/video/Video.mp4: 52-second silent captioned Watch video
- assets/video/Video.vtt: video captions
- question_bank.csv and question_bank_gift.txt
- manifests and audits

Moodle use:
1. Upload or unzip this package into a Moodle file area.
2. Open index.html as the student page.
3. Open teacher_guide.html separately for teacher use.
4. Audio icons are linked to local Edge TTS files in assets/audio/. Story headings play the whole story; small icons play the line.
