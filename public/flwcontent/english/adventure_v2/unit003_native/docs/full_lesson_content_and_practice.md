## Final Project — My Number Challenge Card

**Images:** Image 18 — Project Model Main, Image 19 — Project Support, Image 20 — End / Review Asset  
**Output:** Learners make a simple number challenge card with 2–4 counted picture groups and short oral lines.

### Project steps

- Choose two, three, or four numbers from 0–20.
- Draw simple object groups: stars, balls, flowers, books, apples, bags, or pencils.
- Write or place the matching numerals.
- Ask “How many?” for one picture group.
- Say the mini project script.

### Project model script

- 🔊 Hello. I’m Mia.
- 🔊 How many stars? Three stars.
- 🔊 How many balls? Five balls.
- 🔊 How many flowers? Two flowers.
- 🔊 Goodbye.

### Success check

- I used numbers.
- I used pictures.
- I asked “How many?”
- I said the answer.
- I said hello and goodbye.
