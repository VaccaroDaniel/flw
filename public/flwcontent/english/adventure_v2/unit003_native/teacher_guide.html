Teaching Notes

  • Keep language short and repeated: number + noun, then “How many?”
  • Use pointing, counting aloud, and choral repetition before learners choose answers.
  • For Lesson 6, teach plural -s only as noticing: one star / two stars. Do not introduce grammar tables.
  • For project work, learners can use drawings, stickers, or printed objects. Short spoken output is enough.

Differentiation

  • Support: limit choices to two options first, then return to three-option Practice.
  • Challenge: ask learners to make two “How many?” questions for a partner.
  • Speaking support: allow learners to point and say only the number before saying the full phrase.
